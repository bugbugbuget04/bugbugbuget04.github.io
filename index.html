How I work

Start with the business, not the code.

1. Understand

Read their reviews, menu and Instagram. What do customers keep asking? Where do they give up?

2. Design the flow

Map the path from "just looking" to an order or booking, on a phone first.

3. Build fast

Vibe code with Claude Code. A working demo in hours, so the owner reacts to something real.

4. Test and secure

Click through every path. Domain in the client's name, 2-step logins, no payment pages to fake.
